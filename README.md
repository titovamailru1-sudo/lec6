# Баланс

Учебное приложение на Python и Kivy для учёта финансов. Журнал хранит доходы и расходы с датой, категорией, описанием и суммой, позволяет редактировать и удалять операции, фильтровать их и экспортировать в CSV.

- **Операции.** Баланс равен сумме доходов за вычетом расходов. Суммы хранятся целыми копейками.
- **Аналитика.** Экран показывает доходы и расходы по категориям и по месяцам. Графики Matplotlib встроены в Kivy через Kivy Garden.
- **Синхронизация.** Клиент работает с локальным журналом. По кнопке он объединяет свои операции с копией на REST-сервере. Правки и удаления передаются при следующем обмене.

## Запуск на компьютере

В Linux запустите `./start.sh`. Скрипт создаст локальное окружение и установит зависимости при первом запуске.

Для ручного запуска из папки проекта используйте Python 3.12:

```sh
python -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements.txt
python main.py
```

В Windows команда активации окружения в PowerShell — `.venv\Scripts\Activate.ps1`. На Linux для команды `python` можно использовать `python3`, если это имя установленного интерпретатора.

Операции хранятся в `ledger.json` в папке данных приложения. Там же сохраняется CSV. Чтобы указать свою папку, запустите `python main.py --data-dir ./my-profile`.

## Проверка синхронизации

1. Запустите сервер в отдельном терминале из папки проекта. Серверу достаточно стандартной библиотеки Python.

   ```sh
   FINANCE_SYNC_TOKEN=demo-finance-token-change-me python server.py
   ```

2. Откройте два экземпляра приложения с разными папками данных, например `python main.py --data-dir ./profile-a` и `python main.py --data-dir ./profile-b`.
3. В каждом откройте «Синхронизация», введите `http://127.0.0.1:8765` и токен `demo-finance-token-change-me`.
4. Добавьте операцию в первом экземпляре и нажмите «Синхронизировать» в обоих. Операция появится во втором. Повторите обмен после правки или удаления.

Для обмена через интернет запустите тот же сервер на своём хосте за HTTPS-прокси, укажите его HTTPS-адрес в обоих экземплярах и установите собственный случайный токен. Один экземпляр сервера обслуживает один общий журнал. Данные сервера хранятся в SQLite, путь к базе задаётся параметром `--db`. При правке одной записи на нескольких устройствах применяется версия с более поздней меткой времени.
